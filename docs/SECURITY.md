# Security posture

The default service binds to 127.0.0.1 through the launcher, accepts only CSV uploads, constrains registered paths to `data/inbox`, stores account identifiers as strings, and does not make runtime network calls. Reports are generated from sealed evidence objects. Legal text is template language and must be confirmed by the Investigating Officer. Before production use, add bearer-token enforcement and complete the full upload size, CSV-injection, prompt-injection, and malformed-input suites from the master specification.
